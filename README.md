# 🇺🇸 English

## ✨ About the Project

**Portal of Teyvat** is an interactive web experience inspired by the universe of **Genshin Impact**.

What originally started as a personality quiz to discover which of the seven elements best represents the player has evolved into a complete interactive portal.

Instead of simply answering questions and receiving a result, players create their own **Traveler Profile** and gradually expand it by completing different journeys throughout the website.

The project combines:

* Personality quizzes
* Elemental Visions
* Character affinity
* Teyvat regions
* Traveler profiles
* Achievements
* Exploration progression
* Custom character creation
* Custom Vision creation
* Elemental compatibility
* Wish simulation
* Result cards
* PNG generation
* Result sharing
* Local progression
* Animations and visual effects

The main goal is to create the feeling of entering a small interactive **Teyvat experience**, rather than using a traditional quiz website.

## ❓ Troubleshooting

### Images are not appearing

Check that:

1. The file exists.
2. The filename matches the JavaScript configuration.
3. Uppercase and lowercase letters match.
4. The image is inside the correct folder.

Example:

```text
assets/visions/anemo.png
```

is different from:

```text
assets/visions/Anemo.png
```

on case-sensitive systems.

---

### Generated PNG does not show images

Make sure all images are fully loaded before running html2canvas.

Running the project through a local HTTP server may also solve asset-loading problems.

---

### Progress disappeared

Progress is stored locally in the browser.

It can disappear if:

* Browser storage was cleared.
* Private/incognito browsing was used.
* The project was opened in another browser.
* LocalStorage was manually deleted.

---

### Sharing does not work

The Web Share API depends on browser and operating system support.

When unavailable, clipboard sharing should be used as a fallback.

---

### Audio does not start automatically

Modern browsers commonly block autoplay with sound until the user interacts with the page.

This is expected browser behavior.

The player can enable audio after interacting with the Portal.

Para desenvolvimento, é recomendado utilizar um servidor HTTP local.

## ❓ Solução de Problemas

### As imagens não aparecem

Verifique:

1. Se o arquivo realmente existe.
2. Se o nome está correto.
3. Se letras maiúsculas/minúsculas correspondem.
4. Se o arquivo está na pasta correta.

Por exemplo:

```text
assets/visions/anemo.png
```

pode ser diferente de:

```text
assets/visions/Anemo.png
```

em sistemas que diferenciam maiúsculas e minúsculas.

---

### A imagem da Visão/personagem não aparece no PNG gerado

Certifique-se de que todas as imagens estejam completamente carregadas antes de executar o html2canvas.

Também é recomendado executar o projeto através de um servidor HTTP local.

---

### Meu progresso desapareceu

O progresso fica salvo no navegador.

Ele pode desaparecer caso:

* os dados do navegador sejam apagados;
* o modo anônimo seja utilizado;
* outro navegador seja usado;
* o LocalStorage seja apagado manualmente.

---

### Compartilhar não funciona

A Web Share API depende do navegador e do sistema operacional.

Quando não houver suporte, o projeto deve utilizar a área de transferência como alternativa.

---

### A música não inicia automaticamente

Navegadores modernos normalmente bloqueiam reprodução automática com áudio antes da primeira interação do usuário.

Esse comportamento é normal.

Após interagir com o Portal, o usuário poderá ativar o áudio.
